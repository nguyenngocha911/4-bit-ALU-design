# Introduction
ALU (Arithmetic ogic Unit) is a fundamental block of digital systems and CPUs that performs arithmetic and logic operations on binary data

This project presents the design and implementation of a 4-bit ALU supporting basic arithmetic and logic operations such as addition, subtraction, AND, OR, XOR, NOT using 74HC series ICs

The design consists of 5 main blocks: Input Unit, Output Unit, Control Unit, Arithmetic Unit and Logic Unit
